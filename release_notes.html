Ver. 0.7.0 — 12/05/2026

Added

  • Spend by app in the menu bar widget. Total spend over the last 7 days plus a per-app breakdown of the top spenders, so you can see where the money’s going without opening the app.
  • “Reporting” pill in the toolbar showing your active reporting currency. Click it to jump to Settings → Connections.
  • Toast on org switch confirming “Now showing values in EUR” (or whichever currency) so unit changes never sneak past you.
  • Native-currency tooltip on bid and budget cells. Hover any Daily Budget / Default Bid / Bid Amount / CPA Goal cell to see Apple’s source-of-truth value in the campaign’s billing currency.
  • Live conversion preview when editing bids and budgets — type in the campaign’s native currency, see “≈ $30.00 USD” inline.
  • A clear loading indicator for revenue next to the date picker, plus per-cell shimmer in Ad Group and Keyword tables so you always know what’s refreshing.

Changed

  • Every monetary value is now in your Apple Ads reporting currency. Spend, Avg CPA, Avg CPT, Daily Budget, Bid Amount, CPA Goal, RC Revenue, Net Profit, Net ROAS, summary cards, chart axes, geo map, menu bar, search terms, and chat outputs all share one unit. Per-day FX is applied so historical math is correct, not just today’s.
  • Approximate (≈) prefix on values whose FX rate was unavailable or stale, so you can tell which numbers might shift after the next refresh.
  • Connecting RevenueCat is now nearly instant — revenue shows up within seconds of finishing the connect + match flow instead of needing a long first-time sync.
  • The detail panel’s date picker is now in sync with the main view. Picking 30D in either place updates revenue, spend, and the chart together instead of just the inspector chart.
  • Settings → Connections now shows your reporting currency next to the connected org.

Fixed

  • All Campaigns shows revenue right away on launch instead of needing you to click into an app and back.
  • Revenue starts loading automatically after first RevenueCat connect + match instead of waiting for a click.
  • “Loading revenue…” no longer gets stuck in sessions where the data had already arrived.
  • Snappier screen changes. Opening a campaign or ad group no longer fires duplicate background requests; switching recent date ranges is near-instant.
  • Ad-group and keyword revenue stays scoped to the visible app when switching between apps.
  • Avg CPA / CPT match across rows and toolbar — both now use the install- / tap-weighted formula.

  • Per-app metrics cache is now keyed by scope, so an All-Campaigns view can’t inherit the previous app’s narrowed cache.

Ver. 0.3.0 — 30/04/2026

Added

  • Global search — a single search field that finds campaigns, ad groups, keywords, and search terms across every app at once.
  • Force full resync for RevenueCat — new entry under the Refresh menu wipes the local revenue cache and re-fetches from page 1, behind a confirmation dialog.

Changed

  • RevenueCat revenue sync is dramatically faster and more reliable.
    • Multi-app accounts now sync in parallel instead of one app at a time.
    • The sync resumes where it left off if you quit mid-sync, instead of restarting from page 1.
    • Day-to-day refreshes only re-fetch customers who actually changed since the last sync.
    • Adaptive rate limiting reads RevenueCat’s own headers and slows down before hitting the cap, so big accounts stop hitting 429s.
    • Renewals are now counted in the period they were paid for. Previously a yearly subscription’s full revenue could land entirely on the start date, distorting date-range reports — yearly/monthly totals are split across their actual billing periods.
  • Tables open faster — opening an app’s ad groups or a campaign’s keywords used to fan out one Apple Ads request per row; both are now a single bulk request.
  • Search Terms no longer truncates at 1,000 rows — paginates up to 5,000.
  • Local database moved into its own folder so it can’t collide with other apps. Existing data is migrated automatically on first launch. Downgrading to an older build after this version will show an empty database.

Fixed

  • Reloading after a partially completed sync no longer crashes when duplicate ad-group/keyword rows are present — the duplicates are merged automatically on the next reload.
  • Cancelling a load (e.g. switching tables mid-fetch) no longer silently deletes rows that hadn’t been re-fetched yet.
  • Manual refresh now actually re-fetches metrics even when the entity list hasn’t changed.
  • Sample data (Help → Show sample data) no longer crashes on machines outside UTC.
