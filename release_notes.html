Changelog

All notable changes to ADSwift will be documented in this file.

The format is based on Keep a Changelog, and this project adheres to Semantic Versioning.

Pre-1.0 policy: minor bumps for features and notable changes, patch bumps for bug fixes. 1.0.0 will be cut at the public launch.

[Unreleased]

[0.2.0] - 2026-04-29

Added

  • Add App flow — track apps in the sidebar before any campaigns exist for them. The sidebar’s primary CTA now flips between Connect to Apple Ads (when credentials aren’t set) and Add App (once you’re connected).
  • Search terms table — see the actual search queries that triggered your ads, with a synthesized (Low volume terms) aggregate row that backfills the totals Apple suppresses for privacy.
  • Spend sparkline column on tables for at-a-glance trend without opening a detail view.
  • Recent searches dropdown when filtering tables.
  • Bulk re-enable workflow for paused ad groups (Enable Paused Ad Groups… sheet).
  • Locations picker for campaign geo targeting.
  • Product page picker for ad-group-level App Store product page selection.
  • Inline keyword suggestions inside the keyword and bulk-keyword forms — the standalone Suggestions sheet is gone.
  • Tag-collision pre-flight in release.sh — fails fast if a release tag already exists rather than half-pushing.

Changed

  • Mock-data fallback removed. A fresh install with no Apple Ads credentials now opens the connection sheet directly instead of populating with mock fixtures.
  • Lazy loads keep running across navigation. Ad-group and keyword fetches survive the user navigating between table and detail views mid-fetch — initiated by DataSourceManager itself rather than the calling view.
  • Paywall gating consistency. Sidebar, content overlay, and per-row gates now all route through LicenseStore.contentIsGated(in:). Debug mode is fully unlocked (mock fixtures, nothing real to gate); live mode gates as before.
  • RevenueCat keyword scoping now uses ad-group name instead of numeric ID — RC attribution stores the name, and the parameter labels finally agree.
  • Chat providers narrowed to Claude Code, Codex, and OpenAI-compatible HTTP endpoints (OpenRouter, etc.) — see Removed below.

Removed

  • Direct OpenAI and Anthropic chat providers. Use the OpenAI-Compatible provider with their endpoint URL instead.
  • Standalone Keyword Suggestions sheet. Folded into the keyword form.
  • AppStoreHintsService. Responsibilities folded into AppInfoService.

[0.1.0] - 2026-04-25

Beta

This is a beta release of ADSwift. The app is functional but still under active development — expect rough edges and breaking changes between versions. Feedback is very welcome via Help → Send Feedback… (⌘/).

Added

  • Initial public build of ADSwift.
  • Apple Search Ads campaign management: campaigns, ad groups, keywords, negative keywords.
  • Geo map for campaign visualisation.
  • Campaign assistant chat panel powered by on-device Foundation Models and OpenAI session.
  • RevenueCat revenue store for per-app revenue telemetry.
  • In-app update notifier via Sparkle 2 — the app now checks for updates on launch and every 24 hours, and exposes a Check for Updates… menu item.
