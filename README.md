# adswift-releases

Public release channel for **ADSwift**.

- Landing: <https://saadbelfqih.github.io/adswift-releases/release_notes.html>
- Appcast feed: <https://saadbelfqih.github.io/adswift-releases/appcast.xml>
- Downloads: see [Releases](https://github.com/SaadBelfqih/adswift-releases/releases)

This repo contains only build artefacts — `appcast.xml`, `release_notes.html`, and DMG downloads attached to GitHub Releases. All source code lives in the private `SaadBelfqih/adswift` repo.

Releases are cut by `scripts/release.sh` in the source repo. Do not edit `appcast.xml` or `release_notes.html` by hand — they are regenerated.
