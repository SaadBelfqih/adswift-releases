Changelog

All notable changes to ADSwift will be documented in this file.

The format is based on Keep a Changelog, and this project adheres to Semantic Versioning.

Pre-1.0 policy: minor bumps for features and notable changes, patch bumps for bug fixes. 1.0.0 will be cut at the public launch.

[Unreleased]

[0.2.0] - 2026-04-29

Added

  • Add App — track an app in the sidebar before you have any campaigns for it. The sidebar’s primary button now switches between Connect to Apple Ads and Add App depending on whether you’ve connected.
  • Search Terms table — see the actual queries that triggered your ads, with a (Low volume terms) row that backfills the totals Apple suppresses for privacy.
  • Spend sparklines on tables for at-a-glance trend without opening a detail view.
  • Recent searches dropdown in the table filter field.
  • Bulk re-enable for paused ad groups (Enable Paused Ad Groups… sheet).
  • Locations picker for campaign geo targeting.
  • Product page picker at the ad-group level.
  • Inline keyword suggestions in the keyword and bulk-add forms (the standalone Suggestions sheet is gone).

Changed

  • A fresh install with no Apple Ads credentials now opens the Connect sheet immediately instead of populating the app with mock fixtures.
  • Switching between a table and its detail view mid-fetch no longer cancels the load.
  • Chat providers narrowed to Claude Code, Codex, and OpenAI-Compatible HTTP endpoints (OpenRouter and similar). The direct OpenAI and Anthropic providers were removed — use OpenAI-Compatible with their endpoint URL instead.

Fixed

  • Per-keyword RevenueCat revenue now matches reliably across ad groups (was occasionally missing or mis-scoped).

[0.1.0] - 2026-04-25

Beta

This is a beta release of ADSwift. The app is functional but still under active development — expect rough edges and breaking changes between versions. Feedback is very welcome via Help → Send Feedback… (⌘/).

Added

  • Initial public build of ADSwift.
  • Apple Search Ads campaign management: campaigns, ad groups, keywords, negative keywords.
  • Geo map for campaign visualisation.
  • Campaign assistant chat panel powered by on-device Foundation Models and OpenAI session.
  • RevenueCat revenue store for per-app revenue telemetry.
  • In-app update notifier via Sparkle 2 — the app now checks for updates on launch and every 24 hours, and exposes a Check for Updates… menu item.
